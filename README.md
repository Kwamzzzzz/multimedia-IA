# Student Crypto Dashboard

A student cryptocurrency dashboard demo built with React, Vite, and React Router.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Netlify Deployment

1. Push this project to a Git repository.
2. In Netlify, choose **Add new site** and import the repository.
3. Set the build command to:

```bash
npm run build
```

4. Set the publish directory to:

```bash
dist
```

The included `netlify.toml` also configures these settings and redirects routes back to `index.html` for React Router.

This is a student project and demo only. Do not enter real personal or financial information.
